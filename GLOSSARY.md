# Watch List

A personal watch list that recommends which movie or episodic title to watch next.

## Language

**Available episode**:
An episode that is watchable on the user's streaming service. An estimated air date alone does not
establish availability.

**Availability deferral**:
A temporary exclusion from recommendations for the current episode, lasting a user-chosen number of
elapsed hours, ending automatically or when watch progress changes. It does not change watch history,
recommendation priority, or the season's release schedule.

**Snooze**:
A manual correction for a delayed episode release that adds one week to the current season's
accumulated release delay, shifting estimated availability for its remaining episodes.

**Release delay**:
The accumulated number of weeks added by snoozing within a season to account for releases arriving
later than the weekly estimate. A later season starts with its own release schedule and does not
inherit this delay.
